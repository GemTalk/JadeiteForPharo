# Disclaimer!!! Jadeite for Pharo is still in active development
* No official support provided.
* Any code imported (such as a user's project) must be "rowanized". Filein and Fileout have limited support; see the Jadeite help for details.
* Jadeite for Pharo is not traits aware.

# JadeiteForPharo
IDE for GemStone Smalltalk application development in Pharo

# JadeiteForPharo branches and GemStone/64 versions
* An alpha version for GemStone/S 64 v3.7.2 is on the branch `JftAlpha372`.  Installation instructions are at https://github.com/GemTalk/JadeiteForPharo/blob/JftAlpha372/README.md.
  
* Current development version for GemStone/S 64 v3.7.4.1 is on the branch `main3741`. Installation instructions are at https://github.com/GemTalk/JadeiteForPharo/blob/main3741/README.md.
* GemStone internal users may use builds of v3.7.5, and the JadeiteForPharo branch `main375`. Installation instructions are at https://github.com/GemTalk/JadeiteForPharo/blob/main375/README.md and on the internal wiki page.
